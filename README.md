# DStarix AI Assistant

A production-ready AI Assistant developed as part of the DStarix internship.

The application will integrate:

- Conversational AI
- Retrieval-Augmented Generation (RAG)
- Conversation memory
- Tool calling
- Document upload
- Document-based question answering
- Source attribution
- FastAPI backend
- Streamlit interface

## Project Status

Phase 1 - Project setup and base architecture.
